# Thermal Engitech — Premium Landing Page Upgrade

## What gets delivered

Two things, side by side:

1. **A written suggestions report** — a section-by-section critique of the current site (xd2-sky.github.io/ThermalEngitech) with concrete, actionable improvements across color, typography, imagery, layout, spacing, and consistency.
2. **A live rebuilt landing page** — the current landing page rebuilt in this workspace with the premium upgrades applied, so the difference can be seen and compared in the preview. It is a design demo the user can hand to their developer or adopt directly.

## Art direction

Inspired by the old website (thermalengitech.com) blue-and-white industrial identity, executed at a modern, award-level standard:

- **Light, not dark.** Hero and overall page stay bright — white / off-white base with deep navy and corporate blue. The current site's heavy dark-navy sections get rebalanced so dark is used only as deliberate contrast (one or two bands), not the default.
- **Palette.** Refined version of the existing scheme: crisp white base, deep ink navy for text, one strong industrial blue, and a single warm signal accent (red-orange, used sparingly for key actions and markers — echoing the current red accents but disciplined). No gradients that muddy the palette; depth comes from photography, layering, and shadow.
- **Typography.** A distinctive editorial pairing: a characterful condensed/grotesque display face for headlines, a clean readable sans for body, and a monospace for small uppercase technical labels (certification badges, chapter numbers, spec-style metadata — fits the engineering brand).
- **Imagery.** Real industrial photography (boilers, fabrication, plant floors) treated deliberately: large hero image with a light overlay, clipped/framed product shots with spotlight-style treatment, consistent color grading so photos feel like one shoot. New stock imagery will be sourced where current images are weak or mismatched.

## Signature moments (the "wow" layer)

- **Kinetic hero:** oversized headline with a masked line-by-line reveal on load, staggered supporting elements, and a subtle parallax/depth effect on the hero photograph as the page scrolls.
- **Smooth momentum scrolling** across the whole page (lenis), with framer-motion scroll-triggered reveals on every section — fade/rise, staggered cards, clipped image reveals.
- **Numbered manifesto chapters:** the About / Why-us content reframed as numbered editorial chapters (01, 02, 03…) — a premium, confident structure for an engineering brand.
- **One slow editorial marquee:** a single full-width moving strip (industries served or certification names) as a design accent — one only, kept slow and subtle.
- **Micro-interactions everywhere:** magnetic-feel buttons, hover states on product cards (image zoom, arrow slide), animated stat counters, underline reveals on nav links.

## Assumptions (made so work can proceed)

- **Single landing page only.** The live site has sub-pages (products, about, certifications, request-quote); the demo focuses on the landing page. Nav links point to page sections; the quote CTA links to WhatsApp/email.
- **No backend, no forms.** Contact happens through the existing channels (WhatsApp, phone, email) — no new form backend is built.
- **Real copy is reused** from the current and old sites; only refined where the report recommends it.
- The report is delivered alongside the demo; the demo implements the report's recommendations so both stay consistent.
